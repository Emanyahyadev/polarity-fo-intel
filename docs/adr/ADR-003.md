# ADR-003 — The Policy Engine is the single authority, fail-closed

**Status:** Accepted
**Date:** 2026-08-07

## Context
Autonomous action without an enforcement layer is trust without controls. We
need the authority matrix (what may run autonomously, what needs human review,
what is forbidden) to be applied **before** any action, everywhere, and
identically across engines.

## Decision
`policy_engine.py` loads `policies/authority.json` + `policies/contacts.json`
and resolves every proposed action to Tier 1 (autonomous) / Tier 2 (escalate) /
Tier 3 (refuse). Employees do not auto-approve; the graph consults `decide()`
before running an employee and routes to **END** on any refuse/escalate so
control never continues past an unapproved action. `decide()` additionally
enforces confidence-based release (`may_publish`) and the contact standard
(`contact_review` — generic mailboxes are not named-person routes).

## Consequences
- Fail-closed by design: anything not explicitly Tier-1 is escalated.
- **Positive:** enforcement in control flow, auditable per decision, engine-neutral.
- **Negative:** adding a legitimate autonomous action requires a policy edit
  (a feature, not a bug — the human owns the standard).

Related: ADR-001, ADR-002.
