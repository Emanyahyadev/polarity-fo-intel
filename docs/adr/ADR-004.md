# ADR-004 — LangGraph as default executor with an env-var rollback path

**Status:** Accepted
**Date:** 2026-08-07

## Context
The legacy deterministic Orchestrator loop is stable but rigid. LangGraph offers
checkpointing and interruptible human-approval nodes, but adopting it outright
risks a silent behavior change that could break the operating cycle.

## Decision
`FOINTEL_ENGINE` selects the executor:
- `langgraph` (default) — a LangGraph `StateGraph` over the same employees.
- `orchestrator` — the legacy deterministic loop (rollback path).

Both engines run the **same** employees through the **same** Policy Engine,
thread the same cycle state, write the same JSONL trace, and fill the same
human-review queue. The only difference is the executor. Flipping the env var is
the rollback: no code change. New surfaces (human-approval, checkpointing) are
**off by default** so the autonomous happy path is unchanged.

## Consequences
- Rollback is a config flip, not a code revert.
- **Positive:** the migration bet is bounded; both paths are verified in CI.
- **Negative:** two executors to keep in sync (mitigated by ADR-002 delegation
  and the shared trace contract).
