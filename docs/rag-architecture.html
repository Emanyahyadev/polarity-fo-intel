Micro-RAG · System architecture

Grounded retrieval over 50 verified family offices

A non-technical user asks a plain-English question and gets an answer built only from independently-verified records — or an honest “not enough evidence.” Three separated layers, a hybrid of structured and semantic search, and an anti-hallucination control enforced in code.

family-office-intelligence.onrender.com

One query, two kinds of search

“single-family offices in Texas with AUM over $500M that focus on technology”

The parser splits the question into hard structured filters and a semantic intent. Both run, then fuse.

structured → fo_type = Single-Family structured → hq_state = TX structured → aum_usd > 500,000,000 semantic → “technology focus” (meaning)
Layer 1Presentation
serve/app.py · serve/web

FastAPI + non-technical UI

A live web page and a /query endpoint. Renders each answer with confidence and “verified via” labels; no jargon, no raw JSON. This layer only handles HTTP and rendering.

Layer 2Retrievalhybrid

Structured filtering

Hard filters parsed from the query — family-office type, US state, and numeric AUM thresholds — narrow the set to firms that provably match. Unknown AUM can’t satisfy a threshold, so it’s excluded, not guessed.

Semantic + keyword

Local ONNX embeddings (bge-small) capture meaning; BM25 catches exact terms and firm names. Two ranked lists over the filtered set.

three legs → Reciprocal Rank Fusion → top-k candidates
Layer 3Groundingthe guard
rag/ground.py · enforced in code, not the prompt

Abstain when the evidence is thin; verify every claim

If the best match is below a tuned similarity threshold, or a hard filter matched nothing, the system declines. Generated answers are checked so they only name firms that were actually retrieved — any other firm is treated as a hallucination and dropped.

Grounded answer

Cited to specific record IDs, each carrying provenance and “verified via” sources.

Honest abstention

“I don’t have enough verified information for that” — no false confidence.

Layer 0Datasource of truth
data/final/family_offices.csv

50 independently-verified records

The exact delivered dataset. Every high-value cell carries provenance; retrieval and answers are grounded in this file, so what the app says is always traceable to a source.

How the data earned its place — the pipeline behind the file

01 · discover

Multi-source

SEC 13F · Form ADV · IRS 990-PF · directories — several independent lenses.

02 · enrich

Authoritative facts

SEC submissions, ADV registration, firm sites, and Form 13F (principal, AUM, holdings).

03 · validate

Prove or blank

Firm-type classifier + release gates. Unverifiable cells become honest could_not_verify.

04 · deliver

Select 50

Dedup by identity, cap per source, export with provenance + run manifest.
