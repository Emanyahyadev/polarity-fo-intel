Give the agent a goal, not a search.

Tell it what you're trying to accomplish in plain English — for example, finding and prioritizing prospects for a fund mandate. The agent reads your goal, decides what to look up, checks the evidence behind every candidate, and tells you plainly where it is confident and where it isn't. This takes a few minutes to run — it is doing real multi-step research, not a single lookup.
